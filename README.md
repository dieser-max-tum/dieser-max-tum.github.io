# dieser-max-tum.github.io

## HHL Algorithm Benchmarking Suite

This repository contains a comprehensive benchmarking suite for the HHL (Harrow-Hassidim-Lloyd) quantum algorithm for solving linear systems and machine learning applications.

### Quick Start

```bash
# Install dependencies
pip install -r requirements.txt

# Launch the benchmarking notebook
jupyter lab hhl_algorithm_benchmarking.ipynb
```

### Features

- **Multi-Framework Comparison**: Qiskit, PennyLane, and classical baselines
- **State Tomography**: MLE, Compressed Sensing, and Direct Fidelity Estimation
- **ML Applications**: Ridge regression, linear systems solving
- **Comprehensive Metrics**: Runtime, accuracy, scalability analysis
